현재 ShortBridge 는 TikTok 의 정식 승인 검토 중입니다. 그래서 올린 영상은 모두 "자기만 보기" 로 자동 설정됩니다. 공개하려면 TikTok 앱에서 직접 "모두 공개" 로 바꿔주세요.
  • 발행 가능 대상: 본인 + 미리 등록된 최대 5명까지
  • 계정 조건: TikTok 계정이 비공개(private) 상태여야 합니다
  • 하루 발행 한도: 24시간당 5건 (정식 승인 전 정책)
  • 주의: 음원/캡션 정책 위반 시 계정 영구 차단 가능
정식 승인 후엔 어떻게 달라지나요?
영상을 곧바로 모두 공개 또는 친한 친구 공개 로 발행할 수 있게 됩니다. 발행 한도도 사용자당 24시간 6건 까지 늘어납니다. 승인 검토 기간은 보통 2~4주 입니다.
